Плагины Lumen Agent

Плагин — это файл .plugin: обычный JSON, в котором лежит манифест и код на JavaScript. Код исполняется в изолированной функции и получает объект api с доступом к чату, инструментам агента, интерфейсу и хранилищу. Плагин может добавлять команды, инструменты для модели, виджеты поверх приложения, собственные настройки и текст в системный промпт.

Формат файла

{
  "id": "my_plugin",
  "name": "Мой плагин",
  "version": "1.0",
  "author": "t.me/username",
  "description": "Что делает плагин",
  "icon": "🧩",
  "homepage": "https://example.com",
  "tags": ["fun", "tools"],
  "settings": [
    { "key": "size", "label": "Размер", "type": "select", "default": 1,
      "options": [ { "value": 0, "label": "Маленький" }, { "value": 1, "label": "Большой" } ] },
    { "key": "loud", "label": "Громко", "type": "switch", "default": true },
    { "key": "limit", "label": "Лимит", "type": "range", "min": 5, "max": 100, "default": 20 },
    { "key": "prefix", "label": "Префикс", "type": "text", "default": "•" }
  ],
  "code": "function onLoad(api) { /* код плагина */ }"
}
ПолеОписание
idУникальный идентификатор: латиница, цифры, _ . -. По нему хранятся настройки и данные.
nameНазвание в списке плагинов.
versionВерсия, показывается в карточке плагина.
authorАвтор — видно пользователю.
descriptionОписание, поддерживает переносы строк \n.
iconЭмодзи для карточки.
tagsМассив тегов для каталогов.
settingsСхема настроек: select, switch, range, text. Интерфейс строится автоматически.
codeТело плагина. Обязательно должна быть функция onLoad(api).

Установка

1
Через приложение

Шапка → иконка плагина → «Установить»: выбери файл .plugin, вставь ссылку на него или вставь JSON прямо в поле.

2
Из ссылки в интернете

Подойдёт прямой адрес на raw-файл, например raw.githubusercontent.com/…/plugin.plugin.

3
Готовый пример

Встроенные плагины Clawd и Быстрые заметки уже установлены — их исходники лежат в папке plugins/ репозитория.

Справочник API

Всё начинается с функции onLoad(api). Она может вернуть функцию очистки — она вызовется при выключении плагина.

Жизненный цикл и базовое

МетодЧто делает
api.id / api.name / api.version / api.authorДанные манифеста.
api.log(…)Сообщение в консоль WebView (видно в logcat по тегу LumenWeb).
api.toast(text)Всплывающее сообщение в приложении.
api.cleanup(fn)Зарегистрировать функцию очистки (таймеры, слушатели).
api.on(event, fn)Подписка на событие движка (см. таблицу событий).

Хранилище и настройки

МетодЧто делает
api.store.get(key, default)Читает значение (JSON), хранится в localStorage с префиксом плагина.
api.store.set(key, value)Сохраняет значение.
api.store.del(key)Удаляет ключ.
api.store.keys()Список ключей плагина.
api.store.get("setting.limit")Значение настройки из схемы (после изменения пользователем).

Интерфейс

МетодЧто делает
api.layer()Слой поверх интерфейса (z-index 29) для своих элементов. pointer-events настроен так, что клики по пустым местам проходят в приложение.
api.mount(el)Добавить готовый DOM-элемент в этот слой.
api.theme.accent("#ff8a3d")Сменить акцентный цвет приложения.
api.theme.current()Название текущего акцента.

Чат, события и системный промпт

МетодЧто делает
api.onMessage(fn)Пользователь отправил сообщение: { text }.
api.onAssistant(fn)Модель закончила ответ: { text, message }.
api.onToolResult(fn)Инструмент отработал: { name, output, native }.
api.onChatOpen(fn)Открыт диалог: { id, new }.
api.onTheme(fn)Пользователь поменял оформление.
api.onTick(fn)Раз в секунду: { t } — удобно для таймеров.
api.on("plugin-settings", fn)Настройка плагина изменилась: { id, key, value }.
api.chat.send(text)Отправить сообщение в чат от имени пользователя.
api.chat.inject(text)Добавить скрытую системную заметку в контекст диалога.
api.chat.messages()Видимые сообщения текущего диалога.
api.chat.last()Последнее видимое сообщение.
api.systemPrompt(text)Добавляет текст к системному промпту — так плагин объясняет модели свои инструменты.
api.command({name, description, run})Команда вида /name аргументы в чате. run(argText) возвращает текст ответа.

Инструменты агента

api.tool({
  name: "weather",
  description: "Узнать погоду в городе",
  parameters: {
    type: "object",
    properties: { city: { type: "string", description: "город" } },
    required: ["city"]
  },
  run: function (args) {
    return { ok: true, output: "В " + args.city + " +18°C" };
  }
});

Модель видит такие инструменты как обычные функции и вызывает их сама. Инструменты работают и в нативном режиме (function calling у моделей fast, max, ultra, bare), и в текстовом протоколе (у mini).

Доступ к файлам и терминалу

МетодЧто делает
api.fs.read(path)Прочитать файл (возвращает Promise с { ok, output }).
api.fs.write(path, text)Записать файл.
api.fs.ls(path)Список папки.
api.shell(command)Выполнить команду тем же движком, что выбран в настройках (встроенный шелл или Termux).

Примеры

1. Минимальный плагин: команда

{
  "id": "hello",
  "name": "Привет",
  "version": "1.0",
  "author": "you",
  "code": "function onLoad(api) { api.command({ name: 'hi', description: 'поздороваться', run: function () { return 'Привет, ' + (api.store.get('name', 'друг')); } }); }"
}

2. Инструмент + настройка

function onLoad(api) {
  api.tool({
    name: "todo_add",
    description: "Добавить задачу в список дел",
    parameters: { type: "object", properties: { text: { type: "string" } }, required: ["text"] },
    run: function (args) {
      var list = api.store.get("todos", []);
      list.push(String(args.text));
      api.store.set("todos", list);
      api.toast("Задача добавлена");
      return "В списке " + list.length + " задач";
    }
  });

  api.command({
    name: "todos",
    description: "Показать задачи",
    run: function () {
      var list = api.store.get("todos", []);
      return list.length ? list.map(function (t, i) { return (i + 1) + ". " + t; }).join("\n") : "Пусто";
    }
  });

  api.systemPrompt("Плагин задач доступен: добавляй дела инструментом todo_add.");
}

3. Виджет поверх интерфейса

function onLoad(api) {
  var layer = api.layer();
  var clock = document.createElement("div");
  clock.style.cssText = "position:absolute;right:12px;top:64px;padding:6px 10px;border-radius:12px;" +
    "background:rgba(27,23,20,.9);border:1px solid rgba(255,138,61,.4);color:#f7f2ec;font:600 12px monospace";
  layer.appendChild(clock);

  var timer = setInterval(function () {
    clock.textContent = new Date().toLocaleTimeString();
  }, 1000);

  return function cleanup() { clearInterval(timer); clock.remove(); };
}

4. Реакция на сообщения

function onLoad(api) {
  api.onMessage(function (data) {
    if (/спасибо/i.test(data.text)) {
      api.toast("Пожалуйста! 🙌");
      api.chat.send("Пожалуйста!");
    }
  });
}

5. Полноценный плагин с настройками — Clawd

Пиксельный питомец: рисует себя на canvas в слое плагина, ловит указатель для перетаскивания и полётов, «съедает» элементы интерфейса через cloneNode, говорит фразы, спит по таймеру и добавляет агенту инструмент clawd_say. Полный код — plugins/src/clawd_pet.js в репозитории.

function onLoad(api) {
  var canvas = document.createElement("canvas");
  var layer = api.layer();
  layer.appendChild(canvas);
  var raf = window.requestAnimationFrame ? window.requestAnimationFrame.bind(window) : setTimeout;
  // … отрисовка пиксельного спрайта, физика, реакции …

  api.command({ name: "pet", description: "погладить питомца",
    run: function () { return "Питомец доволен ♥"; } });

  return function cleanup() { cancelAnimationFrame?.(raf); canvas.remove(); };
}

Публикация

1
Собери файл

Создай my_plugin.plugin — JSON с манифестом и кодом. Рекомендуется валидировать на jsonlint.

2
Выложи в репозиторий

Положи файл в папку plugins/ и сделай pull request в github.com/frizovdanyash/agentlumenapi.

3
Поделись ссылкой

Пользователи ставят плагин прямо из приложения по raw-ссылке на файл.

plugins/
├── clawd_pet.plugin
├── quick_notes.plugin
└── src/
    ├── clawd_pet.js
    ├── clawd_pet.meta.json
    ├── quick_notes.js
    └── quick_notes.meta.json

Упаковать исходники в готовые .plugin и во встроенный набор приложения можно одной командой: python3 tools/pack_plugins.py.

Безопасность и FAQ

Что плагин может

Читать и писать файлы в рабочей папке, выполнять команды тем же движком, что у агента, менять интерфейс, читать диалог и добавлять инструменты модели.

Чего не может

Не имеет доступа к сети в обход чата — только fetch средствами WebView, и не может отправлять данные без запроса в коде. Всегда проверяй исходник, как и любой чужой код.

Где хранятся данные

В localStorage с префиксом lumen.plugin.<id>.. Удаление плагина чистит только его ключи, остальное не трогает.

Как отключить всё разом

Настройки → Плагины: тумблер у каждого плагина. Кнопка «Сбросить настройки» в разделе «Данные» удаляет ключ, историю и плагины.
