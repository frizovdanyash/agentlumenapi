Что это

Не просто чат, а рабочий инструмент

Агент умеет читать и писать файлы, запускать команды и помнить весь диалог. Работает на OpenAI-совместимом API Lumen, поэтому ключ один, а моделей пять: от дешёвой mini до топовой ultra.

5 моделей

Mini, Fast, Max, Ultra, Bare — переключение одним тапом в шапке.

Инструменты

bash, чтение и запись файлов, точечные правки, листинг папок.

Терминал

Встроенная песочница команд или настоящий bash в Termux.

Плагины

Расширения на JS: команды, инструменты агента, виджеты поверх интерфейса.

Возможности

Всё, что нужно от агента в кармане

🔑

Свой ключ — свой аккаунт

Ключ Lumen вводит сам пользователь. Хранится в localStorage приложения и уходит только на lumen.unionium.org.

🎨

Кастомизация

8 акцентов, 6 фонов, светлая и тёмная тема, размер шрифта, скругления, плотность, аватары.

⌨️

Терминал как надо

Быстрые кнопки, история по стрелкам, подсветка результата. Встроенный шелл или Termux на выбор.

🧠

Память диалога

История сохраняется целиком, контекст автоматически сжимается — агент не забывает, о чём вы говорили.

🧩

Система плагинов

Файл .plugin = манифест + код. Ставь из файла, по ссылке или вставив текст.

🛡️

Контроль

Опасные команды подсвечиваются и требуют подтверждения. Любой инструмент можно запретить.

Установка

Три шага до первого ответа

1
Скачай APK

LumenAgent-1.1.0.apk — 102 КБ, Android 7.0 и выше. Разреши установку из неизвестных источников.

2
Вставь ключ Lumen

Открой lumen.unionium.org/chat → настройки аккаунта → скопируй токен lum_… → в приложении нажми «Сохранить и проверить».

3
Работай

Проси создать файлы, запускать команды, искать баги. Плагин Clawd уже установлен — просто тапни по экрану.

Хочу настоящий bash

Поставь Termux и выполни в нём:

echo allow-external-apps=true >> ~/.termux/termux.properties
pkg install python git fastfetch

Затем в приложении: Настройки → Движок команд → Termux (или «Авто»).

Где лежат данные

Диалоги, ключ, настройки и плагины — в localStorage приложения. Рабочая папка агента — Android/data/com.lumen.agent/files/workspace. Ничего не уходит на сторонние серверы.

Плагины

Расширяй как хочешь

Плагин — это один файл .plugin (JSON с манифестом и кодом). Он может добавлять команды вида /команда, инструменты для агента, элементы интерфейса, свои настройки и вклад в системный промпт.

🐾

Clawd встроенный

Пиксельный питомец поверх интерфейса: тапы, прыжки, глажка, перетаскивание, полёты, поедание кнопок и кучки. Помнит, что ты говорил, реагирует на «привет», «люблю» и «ахаха», спит, если его не трогать.

Вопросы

Коротко о частом

Приложение не устанавливается

APK подписан debug-ключом: удали предыдущую версию и разреши установку из неизвестных источников.

«Сервер перегружен»

Это ответ API Lumen на перегрузку модели. Переключи модель в шапке — mini и max обычно стабильны.

Нужен ли интернет

Да, для запросов к API. Всё остальное — файлы, история, плагины — работает локально.

Сколько стоит

Само приложение бесплатное. Платишь только Lumen за токены по своему тарифу; mini — самая дешёвая модель.
