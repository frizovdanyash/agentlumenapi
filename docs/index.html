Что это

Не просто чат, а рабочий инструмент

Агент умеет читать и писать файлы, запускать команды и помнить весь диалог. Работает на OpenAI-совместимом API Lumen, поэтому ключ один, а моделей пять: от дешёвой mini до топовой ultra.

5 моделей

Mini, Fast, Max, Ultra, Bare — переключение одним тапом в шапке.

Инструменты

bash, чтение и запись файлов, точечные правки, листинг папок.

Терминал

Встроенная песочница команд или настоящий bash в Termux.

Нативно и быстро

Обычные Android-виджеты: мгновенный запуск, малый вес, без WebView.

Установка

Три шага до первого ответа

1
Скачай APK

LumenAgent-1.2.0.apk — 97 КБ, Android 7.0 и выше. Разреши установку из неизвестных источников.

2
Вставь ключ Lumen

Открой lumen.unionium.org/chat → настройки аккаунта → скопируй токен lum_… → в приложении нажми «Проверить связь» и сохрани.

3
Работай

Проси создать файлы, запускать команды, искать баги. Всё в одном чате, терминал — на соседней вкладке.

Хочу настоящий bash

Поставь Termux и выполни в нём:

echo allow-external-apps=true >> ~/.termux/termux.properties
pkg install python git fastfetch

Затем в приложении: Настройки → Движок команд → Termux (или «Авто»).

Где лежат данные

Диалоги, ключ и настройки — внутри приложения. Рабочая папка агента — Android/data/com.lumen.agent/files/workspace. Ничего не уходит на сторонние серверы.

Терминал

Шелл, к которому не надо идти

Две вкладки: чат с агентом и терминал. Команды можно писать руками — или просить агента выполнить их за тебя, глядя, как он это делает. Три движка на выбор: встроенная песочница, настоящий bash в Termux или «Авто».

📦

Встроенная песочница

ls, cat, mkdir, rm, mv, cp, echo, python3 — из коробки, в папке агента, без лишних разрешений.

❯

Termux RUN_COMMAND

Полноценный bash, установка пакетов, реальные сценарии. Разрешение подтверждает система.

🔀

Режим «Авто»

Простые команды выполняются в песочнице, сложные автоматически уходят в Termux.

Вопросы

Коротко о частом

Приложение не устанавливается

APK подписан debug-ключом: удали предыдущую версию и разреши установку из неизвестных источников.

«Сервер перегружен»

Это ответ API Lumen на перегрузку модели. Переключи модель в шапке — mini и max обычно стабильны.

Нужен ли интернет

Да, для запросов к API. Всё остальное — файлы, история, настройки — работает локально.

Сколько стоит

Само приложение бесплатное. Платишь только Lumen за токены по своему тарифу; mini — самая дешёвая модель.
